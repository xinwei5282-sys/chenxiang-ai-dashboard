# 客户指定的六类图层

以1671×941参考稿为坐标真源，当前入口 `/`，检查入口 `/layers.html`。

| 层 | 内容 | 实际载体 |
|---|---|---|
| 1 | 纯山林全屏底图 | `01-forest-background.png` |
| 2 | 半透明框体 | `.panel-backdrop`，独立CSS背景元素，前景文字不在此层 |
| 3 | 六溯源icon + 四能力icon | `reference-atlas.png` 原稿图集；`src/layer-assets.mjs`定义10个精确区域；10个独立DOM元素 |
| 4 | 中心树、球体、基座、轨道 | `04-tree-orbit.png` 透明PNG，不含节点或文字 |
| 5 | 全产业链状态条背景 | `.status-backdrop`，独立CSS装饰层，状态图标和文字独立 |
| 6 | 顶部与底部背景 | `.header-backdrop`、`.footer-backdrop`，独立CSS装饰层 |

数字、节点名称和状态全部由前端渲染，不再通过隐藏HTML来显示原截图中的文字。图标不是10张独立PNG，而是共用同一原稿图集，独立裁切定位与显隐；便于严格保持原稿图案和颜色。

新增两幅图使用内置imagegen制作，未经知识库入库。纯底图按原稿山林方向去除所有UI和中心物件；中心透明图提取树、蓝球、基座、轨道，排除六节点及文字。生成素材不是原始设计文件的无损图层提取，具体树形/山林纹理会有差异。

右侧数字人和产品保持上一轮呈现，不纳入用户本轮指定的六类拆分。
